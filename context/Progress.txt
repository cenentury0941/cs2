Goal
----
NVIDIA Omniverse/Kit app (SimulCrowd) that loads a venue (GLB→USD),
runs 5–10 intent-driven agents on a NavMesh, demonstrates fire
evacuation from perception, and later swaps rule-based decisions for
batched SLM inference.

Phase 3 — Multiple agents + seats
- Place / discover Seat_* and Exit_* prims (or empties from Blender)
- Spawn 5–10 agents with assigned seats
- Path each agent to its seat (not random destinations)
- Stagger decision / path updates (~1 Hz) for scalability story

Phase 4 — Fire + perception (rule-based)
- Fire trigger with simple VFX / smoke volume (not real CFD)
- Perception: fire_visible / smoke_visible from volume overlap
- Agents replan to nearest Exit_* on EXIT intent
- Optional variety: hesitate, follow nearby agent, pick different exits

Phase 5 — Debug / analytics panel
- Per-agent: id, intent, goal, fire perceived, exit chosen
- Run stats: time to seats, evacuation time, exit usage
