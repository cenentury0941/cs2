Crowd Simulation Project Notes

Project

Develop an NVIDIA Omniverse/Kit application that loads a venue model
(GLB -> USD), simulates 5-10 agents navigating based on intent, and
demonstrates reactions to a simple fire event. The long-term goal is
scalable SLM-driven crowd simulation.

MVP

-   Single venue
-   5-10 agents
-   Assigned seats
-   NavMesh navigation
-   Fire trigger
-   Agents evacuate based on perception
-   Debug/analytics panel

Architecture

Kit Base Editor + custom extension.

Modules: - extension.py - ui.py - simulation.py - navigation.py -
fire.py - ai.py - agent.py

Simulation Loop

Simulation.update() -> Agent.update() -> Decision Engine -> Navigation
-> Update USD transforms

Decision Engine

Initial: - Rule-based decisions

Later: - Replace with SLM implementation using same interface.

Recommended App Workflow

File -> Open Venue Generate NavMesh Spawn Agents Run Simulation Trigger
Fire Observe Agent Behaviour

Project Layout

crowd-sim/ source/ apps/ crowd.sim/ extensions/ crowd.agents/ assets/
venue.usd
